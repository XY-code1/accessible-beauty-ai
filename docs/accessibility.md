# 无障碍使用与人工验收

## 使用说明

- 页面文字流程始终可用。浏览器支持 Web Speech API 时，可使用“开启语音指引”按钮；默认关闭。
- 语音仅播报眼部定位变化、两个练习步骤、启动错误、检查结果和练习完成。开始新播报前会取消旧播报。
- 页面进入后台、离开练习页、关闭摄像头或组件卸载时会停止播报。
- 语音由浏览器原生 `speechSynthesis` 提供，应用不接入云端 TTS，也不会把摄像头图像交给语音功能。
- “高对比度参考线”和“不透明度”只改变参考线显示，不改变会话步骤、拍摄原图或方向检查输入。

## 自动化验证完成

- 语音默认关闭、开关、同一步骤不重复播报、新播报取消旧播报、停止清理及 API 不可用降级。
- 键盘进入和关闭语音、拍摄弹窗焦点进入与返回、两步练习流程。
- 320px 宽度、200% 缩放近似、移动横竖屏和 `prefers-reduced-motion`。
- 高对比与透明度切换不改变当前步骤，参考线不进入算法输入。

## 需要真人验证

- Windows NVDA、macOS/iPhone VoiceOver 和 Android TalkBack 的实际播报顺序、停顿与中文发音。
- 仅键盘、开关控制器及触屏用户能否顺利完成全流程。
- 低视力用户在实际设备缩放、系统大字体和高对比设置下的可读性。
- 听觉提示是否过多、是否与操作节奏冲突。

以上项目均为待执行清单；自动化测试不能证明适用于所有残障人士，也不代表真人美妆操作已经验证。
