# 无界美妆后端 - 自测说明

本文档提供完整的服务启动和接口测试指南。

## 一、服务启动

### 1.1 环境要求

- Python 3.8+
- pip 包管理器

### 1.2 安装依赖

```bash
cd backend
pip install -r requirements.txt
```

### 1.3 启动服务

```bash
# 启动服务（开发模式）
uvicorn main:app --reload --port 8000

# 或使用Python直接运行
python main.py
```

### 1.4 验证服务状态

打开浏览器访问：

```
http://localhost:8000/health
```

预期响应：

```json
{
  "status": "healthy",
  "version": "1.0.0",
  "timestamp": 1697030400.123
}
```

### 2.5 OCR成分识别接口

**接口**: `POST /api/ocr/ingredient`（Base64输入）和 `POST /api/ocr/ingredient/file`（文件上传）

> 注意：完整功能需要安装 OCR 依赖：
> ```bash
> pip install paddleocr paddlepaddle opencv-python numpy
> ```
> 依赖未安装时接口会返回 `OCR_FEATURE_UNAVAILABLE` 提示，不影响其他接口运行。

**测试1：Base64图片识别（JSON请求）**

```bash
# 将图片转为Base64后发送，可选传入 skinTags
curl -X POST http://localhost:8000/api/ocr/ingredient \
  -H "Content-Type: application/json" \
  -d '{
    "imageBase64": "iVBORw0KGgoAA...(省略)...AA==",
    "returnMatches": true,
    "skinTags": ["sensitive", "dry"]
  }'
```

**测试2：文件上传识别（multipart）**

```bash
curl -X POST http://localhost:8000/api/ocr/ingredient/file \
  -F "file=@/path/to/product.jpg" \
  -F "skin_tags=sensitive,dry"
```

**预期返回格式（成功）**：

```json
{
  "success": true,
  "recognizedTexts": ["氧化铁", "生育酚(维生素E)", "甘油"],
  "matchedIngredients": [
    {
      "id": "ing_001",
      "name": "Iron Oxides",
      "nameZh": "氧化铁",
      "category": "着色",
      "description": "常见的眉妆着色剂，提供自然的棕黑色调",
      "benefits": ["持久显色", "自然遮盖", "安全稳定"],
      "cautionGroups": []
    }
  ],
  "warnings": [
    "识别到：氧化铁（着色）",
    "⚠️ 滑石粉 不适合 sensitive 肌肤使用，请注意"
  ],
  "message": "识别完成，发现 1 个成分",
  "unavailable": false
}
```

**预期返回格式（依赖缺失时降级）**：

```json
{
  "success": false,
  "recognizedTexts": [],
  "matchedIngredients": [],
  "warnings": [],
  "message": "OCR_FEATURE_UNAVAILABLE: OCR 功能依赖未安装，请联系管理员安装 paddleocr / paddlepaddle / opencv-python",
  "unavailable": true
}
```

**错误响应（参数/媒体类型）**：

| 状态码 | code | 说明 |
|--------|------|------|
| 413 | `IMAGE_TOO_LARGE` | 图片超过 10 MiB 或 1600 万像素 |
| 415 | `UNSUPPORTED_IMAGE_TYPE` | 非 PNG/JPEG/WebP |
| 415 | `IMAGE_TYPE_MISMATCH` | 文件头与声明类型不一致 |
| 422 | `INVALID_IMAGE_BASE64` | Base64 解码失败 |
| 422 | Pydantic 校验 | 必填字段缺失 |

## 三、完整流程测试

### 测试：意图识别 -> 方案生成

```bash
# Step 1: 意图识别
INTENT_RESPONSE=$(curl -s -X POST http://localhost:8000/api/intent \
  -H "Content-Type: application/json" \
  -d '{"query": "职场面试需要精致的妆容"}')

# 提取参数
SCENE=$(echo $INTENT_RESPONSE | python -c "import sys,json; print(json.load(sys.stdin)['parameters']['scene'])")
STYLE=$(echo $INTENT_RESPONSE | python -c "import sys,json; print(json.load(sys.stdin)['parameters']['style'])")
INTENSITY=$(echo $INTENT_RESPONSE | python -c "import sys,json; print(json.load(sys.stdin)['parameters']['intensity'])")

# Step 2: 方案生成
curl -X POST http://localhost:8000/api/plan \
  -H "Content-Type: application/json" \
  -d "{
    \"parameters\": {
      \"scene\": \"$SCENE\",
      \"style\": \"$STYLE\",
      \"intensity\": \"$INTENSITY\"
    }
  }"
```

## 六、常见问题

### Q1: 启动失败，提示模块找不到

```bash
# 确保在 backend 目录下
cd backend
python -m uvicorn main:app --reload
```

### Q2: OCR功能不可用

安装OCR依赖：

```bash
pip install paddleocr paddlepaddle opencv-python numpy
```

### Q3: 成分数据加载失败

检查 `data/ingredients.json` 是否存在且格式正确：

```bash
python -c "import json; json.load(open('data/ingredients.json'))"
```
